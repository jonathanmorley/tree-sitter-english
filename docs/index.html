3 · Architecture one-way pipeline

Text flows one way — each layer sees only its input. Word classes and phrase structure never enter the grammar: a context-free rule must commit to one reading, so that knowledge lives in later statistical layers.

Segmentation

Paragraphs at blank lines, sentences at .?!, clauses at coordinators and subordinators. A Rust scanner holds the period: initials, 16 curated abbreviations, lowercase-ahead.

Tagging

Greedy perceptron over FNV-1a features, then a width-2 beam re-decode plus sixteen margin-gated correction rules — each admitted with EWT-majority evidence.

Grouping

Greedy chunker over tags with a fixed-phrase trie (as if, because of). No attachment decisions — those belong to parsing.

Parsing & lint

Arc-eager dependencies with labels, then Vale-class rules over syntax a regex linter cannot express: passives, nominalizations, weasels, hedges, vague demonstratives, coordination and negation scope.
